Connect TMDB

CINEPLAY can run entirely from GitHub Pages. Add your own TMDB credential to turn on live trend, search, regional discovery and fresh releases directly in your browser.

Live endpointsTrending · popular · top rated · new releases · India discovery · search
Python ML layerOptional FastAPI + SQL + MongoDB + scikit-learn companion API.
Fallback modeCore CINEPLAY stays usable when either external service is unavailable.
Use a credential you are authorized to use with TMDB. Public client-side credentials can be viewed by visitors, so do not treat a browser-stored API key as a secret.
